# 🌐 Personal Portfolio Website - my-app

This is my personal portfolio website built with React and Tailwind CSS.  
It showcases my projects, technical skills, and background as I transition into a full-stack web developer.

🔗 Live Demo: https://lixinjie520.github.io/my-app/

---

## 🚀 Features

- Responsive design (mobile-friendly)
- Dark / Light mode toggle
- Project showcase section with demo & code links
- About section with skills and certifications
- Contact section with social links
- Smooth scrolling navigation
- Toast notifications for interactions

---

## 🛠️ Tech Stack

- **Frontend**: React, JavaScript (ES6+)
- **Styling**: Tailwind CSS
- **Icons**: React Icons
- **Deployment**: GitHub Pages
- **Build Tool**: Vite
